DESCRIPCIÓ DEL PROJECTE
--------------------------------------------------
EasyTraza és una aplicació dissenyada per facilitar i agilitzar la feina diària dels empleats d'una fleca. L'objectiu principal és digitalitzar i agilitzar al màxim tot el que és la traçabilitat, des dels albarans que es reben dels proveïdors fins als albarans que es lliuren als clients.

El sistema compta amb dues interfícies interconnectades que consumeixen la mateixa API REST (desenvolupada amb Spring Boot):

- Front-end Web: Dissenyada per a fer consultes més complexes i funcionalitats adminitratives.

FUNCIONALITATS PRINCIPALS
--------------------------------------------------
- Control de Traçabilitat (Lots): El sistema permet consultar quins productes s'han creat amb cadascun dels lots consumits.

- Gestió d'Albarans: Creació i edició d'albarans de clients (amb els estats 'Lliurat' i 'No lliurat' per a gestionar les comandes) i albarans de proveïdors, amb opció d'introduir les dades mitjançant OCR.

- Manteniment de Dades (CRUDs): Gestió de Productes, Clients, Usuaris, Matèries Primeres i Proveïdors, amb funcionalitats d'ordenació i filtratge amb tots els camps visibles.

- Identificar-se a l'Android: Sistema d'identificació que permet accedir sense introduir contrasenya, per a estalviar temps als treballadors.

- Seguretat i Sessions: Implementació de Spring Security per a un accés segur mitjançant correu i contrasenya a la web, opcions per editar el perfil i recuperació de credencials.

- Tauler d'Estadístiques: Gràfic per visualitzar l'evolució diària dels productes venuts durant el mes.
